# Planes de ejecución

Acá se guardan los planes persistentes de features o tareas complejas que requieren planificación (ver "Regla de planificación obligatoria" en `CLAUDE.md`).

- Un archivo `.md` por plan.
- **Todo plan debe estar dividido por fases** — no negociable, mejora trazabilidad y revisión de código.

## Al completar un plan

1. Actualizar la documentación pertinente en `/docs` (y en `CLAUDE.md` si el cambio afecta la arquitectura general) con la información relevante del plan.
2. Eliminar el `.md` del plan — no se dejan planes residuales acá.
